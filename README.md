# DGESdocs
Repo para el plugin creado para mostrar los documentos de DGES en su web

# DGES Docs Filtro

Plugin de WordPress desarrollado para la gestión, búsqueda y filtrado de documentos institucionales.

## Instalación para desarrollo
1. Clona este repositorio dentro de la carpeta `wp-content/plugins/` de tu entorno local de WordPress.
2. Activa el plugin desde el panel de administración de WordPress.
